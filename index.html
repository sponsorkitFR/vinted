⚡ Étape 2 sur 3 — recommandé

Auto-remplissage Vinted

Un favori de navigateur qui remplit tout seul le titre, la description et le prix sur Vinted. Choisis ton appareil pour voir les étapes exactes :

  1. Dans l'appli, va dans Réglages → Auto-remplissage Vinted, appuie sur « Copier le code ».
  2. Ouvre Chrome, va sur n'importe quelle page → menu ⋮ → étoile pour l'ajouter aux favoris.
  3. Ouvre tes Favoris (⋮ → Favoris) → ⋮ à côté du favori créé → Modifier.
  4. Renomme-le « Auto-remplir Vinted ».
  5. Appuie dans le champ adresse, appui long → Tout sélectionner → supprime.
  6. Colle le code copié à l'étape 1, en une seule fois, sans rien taper au clavier avant ou après. Enregistre directement.

📸 Étape 3 sur 3

Comment ça marche

  1. Photographie ton article dans l'onglet Nouveau (plusieurs angles = meilleure fiche).
  2. Génère la fiche : titre, description, catégorie, prix et tags arrivent en quelques secondes.
  3. Vérifie et corrige — l'IA peut se tromper sur la marque, l'état ou un défaut, relis toujours avant de publier.
  4. Importe dans Vinted : copier-coller classique, ou l'auto-remplissage ⚡ pour remplir titre/description/prix en un tap.
  5. Ajoute tes photos et publie toi-même — ce dernier geste reste toujours manuel.

Un guide complet et détaillé reste accessible à tout moment depuis Réglages, si jamais tu as un doute.
